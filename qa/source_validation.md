# Source validation

**Trace each metric through its period, unit and original location.**

1. Read the company financial spreadsheet and annual-report page.
2. Match fiscal years and units before comparing values.
3. Keep the original amount, sign and source row.
4. Check the same value in the reported-input worksheet.
5. Keep derived metrics and forecast assumptions separate.
