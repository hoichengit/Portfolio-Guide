The income-statement worksheet contains consolidated earnings: metric names in column A; FY2026, FY2025 and FY2024 in B, D and F. Amounts are USD millions, except EPS in dollars per share. Source em dashes for impairment are normalised to numeric zero. The complete annual report is retained in the local project; GitHub includes the relevant original page and a link to the full report.
