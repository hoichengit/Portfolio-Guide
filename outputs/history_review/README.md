# P&G | Historical market analysis

**Open [the Excel workbook](PG_4_Historical_Market_Analysis.xlsx) to trace company reports into quarterly market comparisons.**

Start with **Review**, then **Product match**. **Model tests** shows calculated sensitivities. The remaining tabs contain matched quarters, company facts, monthly markets, research-only product prices and original source evidence.

- The workbook is created for this project from public sources; it is not a P&G-issued spreadsheet.
- Derived quarterly aggregates and regression results use Excel formulas.
- Formula outputs were compared with an independent Python calculation. A temporary input change was tested and restored in both the calculation engine and Microsoft Excel.
- The scatter chart is editable and linked to cells.
- This is a historical diagnostic workbook. It does not turn the coefficients into a validated scenario forecast.
