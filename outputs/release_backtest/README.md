# P&G release-aware backtest

**Open [the workbook](PG_5_Release_Aware_Backtest.xlsx) to compare forecasts made with information available at each historical date.**

Start with **Review** for model errors and **Quarter example** for the January–March 2026 Grooming pricing timeline. The remaining worksheets show scores, forecasts, training pairs, observed/estimated market months, company facts and original market versions.

- The workbook was created for this project from public sources; it is not a P&G-issued Excel file.
- Fitted coefficients, forecasts, blends, errors and scores use formulas and were checked against the independent Python analysis.
- Target actuals are used for scoring only. Changing the January–March 2026 actual does not change forecasts made before its publication.
- Dates/market inputs are preserved extracts. New release ingestion requires rerunning the data workflow.
- The chart is editable and linked to cells.
- This historical model-development exercise does not establish a final sales scenario or a causal relationship.
