# Original data — NKE

- [FY2026 annual report](NKE_2026_Annual_Report.pdf): original company PDF, unchanged.
- [Extracted statement inputs](statement_inputs.csv): our transcription, **not an Excel file downloaded from the company**.
- [Machine-readable inputs](statement_inputs.json): numeric values, metric keys and PDF page references.

Amounts are **USD millions**, except per-share amounts, percentages and days. Dates follow each company's fiscal year: 31 May. The report compares FY2026 with FY2025 actuals. It is not a budget comparison or a forecast. The annual-report PDFs are the source; the Excel analysis and calculated ratios are our work.

Source screenshots are cropped from these PDFs. Red outlines are added for emphasis; reported text is unchanged. Where a crop omits year headings, its caption specifies the source column order. P&G's independently rounded figures can leave a $1m reconciliation difference. NIKE operating profit before other income is kept separate from its company-defined EBIT.
